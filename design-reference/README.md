# Design reference

These are the approved mockup pages, exported from a prototyping canvas. They use a canvas-specific template format (`<x-dc>`, `{{holes}}`, `sc-for`), so they will not run on their own. Use them for layout, copy, colours, spacing and interaction behaviour, then rebuild them in the real stack.

- Main.html: catalogue (drawers, sub-drawers, sorting, expanding cards)
- Network.html: the who-used-what graph
- Search.html: dense search results
- Submit.html: the submission form
- Review.html: the editor's review queue
- About.html: the About page
